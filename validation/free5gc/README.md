# Independent protocol validation

Run `npm run test:protocols` from the repository root with Go 1.27.2 (validation toolchain only) and Rust installed. This emits endpoint plaintext NAS and actual NGAP frames using the engine, then passes them to the separately implemented [free5GC NAS](https://github.com/free5gc/nas/tree/v1.1.5) and [NGAP](https://github.com/free5gc/ngap/tree/v1.0.10) codecs. The versions and transitive dependencies are pinned in go.mod/go.sum.

Thirty frames cover initial registration/authentication/security/accept/complete, UL/DL N1 with a multi-label DNN and SST/SD, PDU resource setup/response/release, 5GSM accept/reject/release, unforwarded-payload cause 91 and N2 UE context release. Every decoded frame must re-encode byte-for-byte. The setup request transfer is also independently APER decoded/re-encoded; its tunnel, session type, QoS list and session-AMBR IEs must be present. No sockets, external core, service credentials or deployment are used.

This caught OxiRush 0.4.2's macro mapping `RRCEstablishmentCause` to IE 237 instead of 90. The application's explicit adapter fixes this and a native regression test locks the required IE ID. The non-GBR setup now includes the N2 session-AMBR IE matching the NAS 1 Mbit/s profile. Rate enforcement remains outside the user-plane model.

The original 30-frame check validates encoding only. The same command now also runs thirteen interactive endpoint tests with independently derived MILENAGE/KDF/NAS keys and actual protected wire messages. See [exact peer scope and reliability evidence](../../docs/interop-validation.md). Registration is driven independently in both roles; the shared one-session SMF allocation/policy/release state machine and bounded T3592/AUTS procedures are independently driven. No live SCTP/core interoperability or conformance certification is claimed.

The validator is a separate local/CI executable, never compiled into browser assets. Its nine linked dependencies (including the test graph) are Apache-2.0, MIT, BSD-2-Clause or BSD-3-Clause. Reviewed versions and license hashes are in LICENSES.json, with notices retained under notices/. `python3 scripts/check-validation-licenses.py` checks the actual linked module graph and notice hashes. No AGPL/GPL implementation source is incorporated into RANterra.


Validation-only audit exception: [GO-2022-1083](https://pkg.go.dev/vuln/GO-2022-1083) reports malformed-input panics in free5GC APER, with no fixed release listed. The checker consumes locally generated bounded fixtures and endpoint responses in separate test processes, has no network listener, and turns panics into test failures. Do not use this validator to serve or ingest arbitrary uploaded traffic. It is absent from browser/native application dependencies. `python3 scripts/audit-validation.py` pins Go 1.27.2 and govulncheck 1.9.0, retains the JSON audit, reports this exception visibly and fails on any additional reachable advisory. The initial system-Go 1.23.2 scan also found a standard-library advisory; the pinned 1.27.2 scan removed that finding. This validation tool is not represented as vulnerability-free.

The interactive suite now contains thirteen tests, including shared SMF allocation/policy/release, pending and active traffic gating, gNodeB-allocated downlink TEIDs, T3592 retry/exhaustion, N2 timeout, and AUTS generation/verification in both directions. The adapter calls `smf::Smf`, the same implementation as the browser engine. See [scope, timer assumptions and omissions](../../docs/interop-validation.md). These are independent test peers over local encoded-message boundaries; no running free5GC core or SBI/PFCP interoperability is claimed.
